\section{Base-level alignment}
\label{sec:final-alignment-role}
\label{sec:final-alignment-cpu-contracts}

In this short chapter I want to discuss last parts of the pipeline's algorithms. The first one is the base-level alignment.
Chaining will tell us approximetely where two sequences match, but it isn't sufficient to tell which exact symbols correspond to which. The base-level alignment performs the dynamic programming specified in the introductory sections~\ref{sec:exact-dp} as
now instead of matching entire target, we can just process target subsequence of size similar to the query size.

\info{Conditional CIGAR execution}{
BioseqDB doesn't call base-level alignment if no \path{bioseq.cigar()} is requested~\ref{lst:xdrop-zdrop-strategies}, so
then \path{bioseq.score()} only reflects the chaining score. If \path{bioseq.cigar()} call is present in the SQL query, then score represents results of the final alignment (thus score can differ  depending on the query).
This is explained in the walkthrough appendix~\ref{app:sql-walkthrough}.
}

In BioseqDB I used existing implementation of KSW2 (the algorithm by the author of minimap2 that uses AVX SIMD C intrinsics to implement DP calculations)
from minimap2 and Block Aligner~\cite{minimap2_paper,block_aligner_paper}.
The DP formulations follow what was described already easlier~\ref{sec:exact-dp}, where KSW2 provides various flavours of functions in its API primarily left/right extension and local mode~\ref{fig:alignment-boundary-modes}.
KSW2 uses banded alignment where the maximum distances are fixed (for more details on that see chaining for maximum diagonal distance (bandwith)~\ref{fig:chaining-dotplot})
The block aligner is more complex and uses moving square blocks to adaptively set this size of "bandwith", where we compute scores in the score matrix.

I previously introduced X-drop and Z-drop concepts~\ref{lst:xdrop-zdrop-strategies}, but formally they can be formulated as follows.
Let's say \(S^\star\) is the best score reached at \((i^\star,j^\star)\) and we test this best score against the
current score \(S\) at \((i,j)\) (meaning that we are matching $i$th symbol of target vs. $j$th symbol of query):
\begin{equation}
\begin{aligned}
  \text{X-drop:}\quad&S^\star-S>X,\\
  \text{Z-drop:}\quad&S^\star-S>Z+e_{g}\left|(i-i^\star)-(j-j^\star)\right|.
\end{aligned}
\label{eq:zdrop}
\end{equation}
$e_{g}$ here is gap-extension penalty, which in this context means that we can disard all symbols from the best score to the current position by introducing a gap. This means 
that effectively we just stop earlier if the distance from the diagonal gets to large, so practically Z-drop is more restrictive for correct setup.

\section{How Block Aligner follows the alignment}
\label{sec:final-alignment-block}

Block Aligner moves a \(B\times B\) square through the scoring matrix,
and internally compute strips of width \(s=8\) visible on the figure~\ref{fig:block-adaptive-reconstruction} below. 


Border scores guide its direction;
stalled progress triggers a return to a checkpoint and a larger block
(Figure~\ref{fig:block-adaptive-reconstruction}). The following formulation
adapts the paper's Algorithm~1 to BioseqDB's sequence-to-sequence port;
the upstream README also describes these heuristics~\cite{block_aligner_paper,block_aligner_readme}.
A finite block limit can exclude a better path outside the computed cells.

Let \(m=|Q|\), \(n=|T|\), with DP coordinates starting at \((0,0)\).
For substitution scores \(\sigma\) and gap cost \(q+e\ell\), \(D,C,R\)
denote the score and horizontal/vertical gap tables. Their boundary values are
\[
 D_{0,0}=0,\qquad D_{i,0}=R_{i,0}=-q-ei,\qquad
 D_{0,j}=C_{0,j}=-q-ej\quad(i,j>0).
\]
All other unavailable scores, including cells outside
\([0,m]\times[0,n]\), are \(-\infty\).
\(\Call{Rect}{r,c,h,w}\) evaluates the affine recurrence on
\([r,r+h)\times[c,c+w)\), updates the borders and trace \(\tau\), and
returns the maximum score and its coordinates; an empty rectangle returns
\((-\infty,\bot)\). The shared state \(\mathcal S=(\mathcal F,\tau)\)
contains the four border vectors
\(\mathcal F=(D_{\rm right},C_{\rm right},D_{\rm bottom},R_{\rm bottom})\).
Checkpoint assignment copies these vectors and saves the trace-stack position;
restoration discards the later trace. Scores below are absolute, omitting
SIMD score offsets.

For the current block \([i,i+B)\times[j,j+B)\), define
\begin{equation}
\begin{aligned}
 r_s&=\max_{0\leq k<s}D_{i+k,j+B-1},&
 b_s&=\max_{0\leq k<s}D_{i+B-1,j+k},\\
 h_s&=\max_{B-s/4\leq k<B}
       \{D_{i+k,j+B-1},D_{i+B-1,j+k}\}.&&
\end{aligned}
\label{eq:block-border-decisions}
\end{equation}
Thus direction uses border prefixes of length \(s\), while shrinking tests
suffixes of length \(s/4=2\). Brackets \([P]\) denote the indicator of \(P\).

\begin{algorithm}[H]
\caption{Adaptive Block Aligner: explicit block and boundary updates}
\label{alg:adaptive-block-alignment}
\footnotesize
\begin{algorithmic}[1]
  \Require $Q,T,\sigma,q,e,B_{\min},B_{\max},X$; $\chi\in\{0,1\}$
    \Comment{$\chi=1$: X-drop; $\chi=0$: global}
  \Require $B_{\min},B_{\max}\in\{2^k:k\geq3\}$, $B_{\min}\leq B_{\max}$
    \Comment{bounds adjusted to the SIMD lane count}
  \Statex \textbf{Constants:} $(m,n,s)=(|Q|,|T|,8)$
  \Statex \textbf{Global:} $\mathcal S=(\mathcal F,\tau)$
    \Comment{per-call state shared with \(\mathrm{Rect}\)}
  \Statex \textbf{Local:} $i,j,B,B_0,u,z\in\mathbb N_0$;
    $d\in\{\mathsf R,\mathsf D,\mathsf G\}$; checkpoint $\mathcal K$
  \Statex \textbf{Local:} $M,M_1,M_2,S^\star\in\mathbb Z\cup\{-\infty\}$;
    $p,p_1,p_2,p^\star\in\mathbb N_0^2\cup\{\bot\}$; $v\in\{0,1\}$
  \State $(i,j,B,B_0,u,z)\gets(0,0,B_{\min},0,0,0)$
    \Comment{$u$: stalled steps; $z$: X-drop steps}
  \State $(S^\star,p^\star,d)\gets(0,(0,0),\mathsf G)$; $\tau\gets\varnothing$
  \State $\mathcal F\gets\Call{InitBorders}{\sigma,q,e}$; $\mathcal K\gets(i,j,\mathcal S)$
    \Comment{boundary values above}
  \While{true}
    \If{$d=\mathsf R$}
      \State $(M,p)\gets\Call{Rect}{i,j+B-s,B,s}$ \Comment{new right strip}
    \ElsIf{$d=\mathsf D$}
      \State $(M,p)\gets\Call{Rect}{i+B-s,j,s,B}$ \Comment{new bottom strip}
    \Else
      \State $(M_1,p_1)\gets\Call{Rect}{i+B_0,j,B-B_0,B_0}$ \Comment{$\Omega_1$: grow down}
      \State $(M_2,p_2)\gets\Call{Rect}{i,j+B_0,B,B-B_0}$ \Comment{$\Omega_2$: grow right}
      \State $(M,p)\gets (M_1>M_2)\ ?\ (M_1,p_1):(M_2,p_2)$
      \State $\mathcal K\gets(i,j,\mathcal S)$ \Comment{checkpoint at the enlarged size}
    \EndIf
    \State $u\gets u+1$; $v\gets[M>S^\star]$
    \If{$v=1$}
      \State $(S^\star,p^\star,u)\gets(M,p,0)$; $\mathcal K\gets(i,j,\mathcal S)$
    \EndIf
    \State $z\gets(z+1)[M<S^\star-X]$
    \If{$(\chi=1\land z=2)\lor(i+B>m\land j+B>n)$}
      \State \textbf{break} \Comment{X-drop or both sequence ends}
    \EndIf
    \If{$j+B>n$}
      \State $(i,d)\gets(i+s,\mathsf D)$; \textbf{continue} \Comment{right edge reached}
    \EndIf
    \If{$i+B>m$}
      \State $(j,d)\gets(j+s,\mathsf R)$; \textbf{continue} \Comment{bottom edge reached}
    \EndIf
    \If{$2B\leq B_{\max}\land\bigl(u\geq B/s\lor(d=\mathsf G\land v=0)\bigr)$}
      \State $(B_0,B,d,u)\gets(B,2B,\mathsf G,0)$
      \State $(i,j,\mathcal S)\gets\mathcal K$; \textbf{continue} \Comment{restore before growing}
    \EndIf
    \If{$B>B_{\min}\land v=1\land h_s\geq M$}
      \State $B\gets B/2$; $(i,j)\gets(i+B,j+B)$
      \State $\mathcal F\gets\mathcal F[B:2B)$; $\mathcal K\gets(i,j,\mathcal S)$
        \Comment{suffix of each border vector}
    \EndIf
    \State $d\gets(r_s\geq b_s)\ ?\ \mathsf R:\mathsf D$
      \Comment{evaluate on the current borders}
    \State $(i,j)\gets(i+s[d=\mathsf D],j+s[d=\mathsf R])$
  \EndWhile
  \State \Return $(\chi=1)\ ?\ (S^\star,p^\star,\tau):(D_{m,n},(m,n),\tau)$
\end{algorithmic}
\end{algorithm}

\noindent\label{sec:final-alignment-fused-work}
Traceback from the returned endpoint produces the CIGAR when requested.
One alignment call includes scoring, trace storage, traceback and CIGAR
construction. BioseqDB can skip Block DP when a score bound proves that an
equal-length fill's straight diagonal is uniquely optimal. The timer in
Section~\ref{sec:bench-a-b} includes this shortcut too.
