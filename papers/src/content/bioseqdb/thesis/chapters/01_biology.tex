\section{Biological context}
\label{sec:biology-sequences}

"Significant scrutiny and attention have been given to genome-sequencing costs and how they are calculated since the beginning of the field of genomics in the late 1980s". \cite{nhgri_sequencing_cost_2026}
NHGRI (National Human Genome Research Institute) has carefully tracked costs per genome and expose this data publically.


In the last 15 years, there has been seen a massive development of sequencing technologies. Companies like Applied Biosystems, Illumina, Roche, and Pacific Biosciences have developed a plethora of sequencing platforms, e.g. SOLiD, GS FLX, and PacBio. These tools are able to generate an enormous amount of data in a matter of days. As an example, Illumina NextSeq generates up to 360 Gbp, split into reads of length up to 150 bp in merely 2 days (data taken from Illumina website). \\
 
\noindent Although those platforms vary in detail, the general idea behind them is as follows:
\begin{enumerate}
\item DNA is fragmented through physical and chemical methods. Adapters are appended to the ends of the fragments to form what is called a sequencing library.
\item Fragments of unwanted size or self-ligated adapters are removed from the library.
\item The library is immobilized on a chemical bead so that it can be steadily observed.
\item Amplification is performed, e.g. through PCR emulsion
\item A combination of optical devices and fluorophores is used to make reads.
\end{enumerate}

With new advancements in sequencing technologies, the cost of sequencing a genome has been decreasing significantly to the point where most popular open databases store more than 10s of petabytes of data.
To make this data usesable researchers often need to perform search operations:
\begin{itemize}
\item For bioinvestigative resarch: does this genomic sequence already contains known genes? Does it contain a known mutation? Is it a known pathogen?
\item For evolutionary biology: is this genomic sequence a known evolutionary lineage? What is the genetic distance between this sequence and a known sequence?
\item For legal research: is this DNA sample from known individual? Does it represent known kinship to someone else?
\end{itemize}
This search operation is using an operation called "sequence alignment" which is the core concept of this thesis.

\subsection{DNA, ribonucleic acid (RNA), and protein alphabets}

DNA is a polymer containing one of four bases:
adenine, cytosine, guanine and thymine. Their conventional one-letter symbols
form the alphabet
\[
  \Sigma_{\mathrm{DNA4}} =
  \{\mathtt{A},\mathtt{C},\mathtt{G},\mathtt{T}\}.
\]

Four symbols are sufficient for an unambiguous DNA string, but experimental
data introduces ambiguity. The symbol \(\mathtt{N}\) conventionally means
that the nucleotide at a position is unknown or was not resolved. Other
International Union of Pure and Applied Chemistry (IUPAC) codes describe sets
of possible bases, such as a purine at a position.

RNA uses adenine, cytosine, guanine and uracil, so a basic RNA alphabet replaces
\(\mathtt{T}\) with \(\mathtt{U}\). Many RNA molecules are transcribed from
DNA. \cite{crick_central_dogma_1970}

A protein sequence is written over the twenty common amino-acid symbols. It's alphabet is notably larger, but in most cases we can translate it to a DNA sequence and use the DNA alphabet directly.

\section{Alignment operation}

Due to nature of biological sequences, search must be able to match fragments that are non-exact, thus alignment operation is similar to popular fuzzy-search operations on normal text.
The alignment can be viewed as a processes that optimises gaps (insertions and deletions) in a way to optimise similarity metric. High similarity score between parts of sequences can indicate that they share same evolutionary origin or have a common purpose. By comparing newly found sequences to already researched ones, we can deduce lots of relevant biological data. \cite{zpp_bio}

We will consider finite nonemptystrings over the DNA4 alphabet. A gap is a symbol indicated by \texttt{-}. An alignment is a process of adding gaps to the sequences so that they are of the same length and at the same time, there is no index where a gap occurs in both sequences.

\noindent There are 4 cases that can occur during alignments:
\begin{enumerate}
\item Insertion - a gap has been added to the first sequence
\item Deletion - a gap has been added to the second sequence
\item Mismatch - letters at a given index are different
\item Match - letters at a given index are the same
\end{enumerate}


\section{Technical considerations}

A typical workflow for sequence analysis includes $3$ data formats - FASTA, FASTQ, and SAM/BAM. Reference genome, stored in FASTA, is aligned with millions of reads in the FASTQ file and the result of alignment is saved as SAM/BAM file. The reason for the reference genome being in FASTA and reads in FASTQ is that we assume that the reference genome is correct, but reads produced by sequencers can contain various errors. Moreover, we're more likely to score alignments with high-quality bases higher than the ones with low-quality.

\subsection{FASTA}

FASTA is a text-based file format for storing nucleotide sequences. It is one of the most widely used formats in bioinformatics. The current standard specification is given by NCBI. Below is a description of the usually encountered version. \\

\noindent It consists of a series of entries separated by a new line. Each entry starts with a single-line header. The header starts with \texttt{>} and contains various metadata about the following sequence, like the description of the sequence, library accession number, and submission date. After the header comes the sequence itself represented with standard IUB/IUPAC acid codes, split into lines of length usually not exceeding $80$ characters. Aside from A, C, T, G commonly encountered is code N, which means any of A/C/T/G. Lowercase letters are treated the same as uppercase. The usual extension is .fasta and .fa. An example FASTA file:

\begin{FastxFile}[fasta]

ACTATAGGAGCAGANNNNNNNNCTAGAGACATC
TCTGCGTNTNTTCCGGACGTACGTAGCATAGTC
\end{FastxFile}

\noindent The advantages of this format are simplicity and human readability. The downside is that it is not optimal in terms of size. To adhere to this issue, compression software is used, like gzip.


\subsection{FASTQ}

FASTQ is an extension of the FASTA format. It enhances FASTA by adding quality scores of sequences. It is a standard output format of sequencers. \\

\noindent Each entry consists of $4$ lines. The first line starts with \texttt{@} and contains metadata about the sequence. The second line contains the sequence itself. The third line starts with \texttt{+} and may contain some additional metadata. The fourth line contains quality scores, represented by ASCII characters with codes from $33$ to $126$, one character per nucleotide. The file extension used is .fq and .fastq. Again, gzip can be used to reduce file size. An example FASTQ file:

%TODO: This verbatim with nice tikz diagram where on the left side we have text (simialr to FASTA example) with line for "indentifier", "sequence", "quality scores" and "+ sign and identifier"
\begin{FastxFile}[fastq]
(*@\FastxHeaderLine{@HumanGenomeSequencerRead}@*)
ACTACTAGACGG
(*@\FastxSeparatorLine{+Genome20200301}@*)
(*@\FastxQualityLine{*!]^#[$*@*!(}@*)
\end{FastxFile}

\noindent The quality score is usually a phread score, meaning $Q$ satisfies $Q = -10 \log_{10} p$, where $p$ is the probability of a corresponding nucleotide being incorrect. ASCII codes from $33$ to $126$ are mapped from $0$ to $93$.

\subsection{CIGAR}

CIGAR is an acronym for Concise Idiosyncratic Gapped Alignment Report and has been originally defined by the Exonerate alignment program. The CIGAR format is designed to contain the minimal information necessary for the reconstruction of an alignment. This format does not include nucleotides.
\cite{cigar_nbis_explained}

\begin{itemize}
\setlength{\topsep}{.35\baselineskip}
\setlength{\itemsep}{.12\baselineskip}
\setlength{\parsep}{0pt}
\item M - match or mismatch
\item D - deletion
\item I - insertion
\item S - soft clipping. Can occur only at the beginning or at the end of the alignment. Indicates that nucleotides are clipped from the alignment.
\item H - hard clipping. The same as soft clipping, except that the clipped part is not present in the SEQ field of the SAM file.
\item N - skipped region. Used for representing introns (part of the gene that is non-coded) in the alignment.
\item = - match
\item X - mismatch
\end{itemize}
