SQL API

SQL API reference

  • bioseq.cigarsql_functionCIGAR operations for the current mmsearch alignment. The operations describe matches, mismatches and gaps when base alignment ran.
  • bioseq.lensql_functionCount sequence letters using the stored length.
  • bioseq.query_endsql_functionExclusive end offset of the alignment on the query sequene.
  • bioseq.query_startsql_functionZero-based start of the alignment on the query sequence.
  • bioseq.symbol_countsql_functionCount occurrences of one alhabet symbol in a sequence.
  • bioseq.target_endsql_functionExclusive alignment end on the original target sequence.
  • bioseq.target_startsql_functionZero-based alignment start on the original target sequence.
  • bioseq_cache.entriessql_functionDescribe exact and reusable cache generations. The caller's role determines which identifying fields and SQL text are shown.
  • bioseq_cache.invalidate_allsql_functionRetire all exact and reusable cache generations. Requires a PostgreSQL superuser.
  • bioseq_cache.invalidate_relationsql_functionRetire cache generations that depend on the given relation. Requires a PostgreSQL superuser.
  • bioseq_cache.reset_statssql_functionReset the shared public cache counters. Requires a PostgreSQL superuser.
  • bioseq_cache.statssql_functionRead the shared cache counters after checking diagnostic access.
  • bioseq_cache.versionsql_functionReturn the installed cache extension version.
  • public.mmsearchsql_functionRequest similarity search with default aligner options. The planner must replace this marker with a Bioseq custom scan. Direct Boolean execution raises an error.
  • public.mmsearchsql_functionRequest similarity search with per-call aligner options. A null target or query returns SQL NULL. Other calls require a Bioseq custom scan to execute the search.
  • bioseq.seqsql_typePostgreSQL sequence value with packed letters and an alphabet tag. PostgreSQL can compress or move large values into TOAST storage.
  • public.bioseq_aligner_optionssql_typeAligner settings for one mmsearch call. NULL fields use the corresponding session setting.
  • public.mmsearchoverload_groupOverloaded SQL function with 2 signatures.
