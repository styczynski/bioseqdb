bioseq_internal.external_relation_options

Store custom options for a bioseq_external table.

PostgreSQL 17 provides no custom table-access callback for these relation options. Keep the external entity and sequence settings in this catalog, where Bioseq can validate and restore them with the table.

Examples#

Inspect the external entity and sequence layout configured for each table.

Fields#

NameTypeDescription
regclassregclassOID of the external table whose options are recorded.
entitytextExternal entity kind: taxonomy, catalog, record_gene, record_location, sequence, or sequence_chunk.
alphabettextAlphabet selected for external sequence values.
storage_widthinteger = 0Packed sequence storage width; the catalog permits values from 0 through 64.
chunk_basesinteger = 0Configured number of bases per external sequence chunk; must be nonnegative.

Attributes#

access_method
"heap"
constraint external_relation_options_chunk_bases_check
CHECK ((chunk_bases >= 0))
constraint external_relation_options_entity_check
CHECK (((entity IS NULL) OR (entity = ANY (ARRAY['taxonomy'::text, 'catalog'::text, 'record_gene'::text, 'record_location'::text, 'sequence'::text, 'sequence_chunk'::text]))))
constraint external_relation_options_pkey
PRIMARY KEY (regclass)
constraint external_relation_options_storage_width_check
CHECK (((storage_width >= 0) AND (storage_width <= 64)))
