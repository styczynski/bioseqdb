bioseq_internal.sequence_source_version

Version and checksum for a stored sequence and its fragment range. PostgreSQL row visibility determines which version a reader can use. The checksum is computed when the sequence is inserted State 0 means the sequence is awaiting publication, 1 means ready, and 2 means invalid.

Examples#

As a catalog owner, inspect stored sequence versions and publication states.
