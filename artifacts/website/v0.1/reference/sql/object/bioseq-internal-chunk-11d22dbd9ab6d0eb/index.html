sql · table

bioseq_internal.chunk

Locations, compression details and min/max values for one column chunk.

Examples#

Compare the stored and decompressed sizes of each column value stream.

Fields#

NameTypeDescription
storage_idbigintStorage generation containing this column chunk.
stripe_numbigintStripe containing this column chunk.
attr_numintegerPostgreSQL attribute number of the stored column.
chunk_group_numintegerChunk group containing this column chunk.
minimum_valuebyteaSerialized minimum value used to skip chunks during filtering, when available.
maximum_valuebyteaSerialized maximum value used to skip chunks during filtering, when available.
value_stream_offsetbigintByte offset locating the stored value stream.
value_stream_lengthbigintLength of the stored value stream in bytes.
exists_stream_offsetbigintByte offset locating the presence-bit stream for NULL handling.
exists_stream_lengthbigintLength of the presence-bit stream in bytes.
value_compression_typeintegerNumeric identifier of the value-stream compression algorithm.
value_compression_levelintegerCompression level used for the value stream.
value_decompressed_lengthbigintSize of the value buffer before compression, in bytes.
value_countbigintNumber of rows represented by this column chunk.
