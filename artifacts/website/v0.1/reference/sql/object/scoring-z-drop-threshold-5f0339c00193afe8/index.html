bioseq.aligner.scoring.z_drop_threshold

Stop extension when its score falls too far below the besw score. Z-drop adjusts the comparison for gaps. Negative one disables it.

Sets KSW2's Z-drop threshold or BlockAligner's X-drop threshold for end extensions. BlockAligner extensions require a nonnegative value.
