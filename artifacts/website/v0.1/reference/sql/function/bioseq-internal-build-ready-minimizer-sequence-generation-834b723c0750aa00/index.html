bioseq_internal.build_ready_minimizer_sequence_generation

Build a stored whole-sequence minimizer index for a SQL test. Publish and verify, the generation, release temporary sort runs, and return build counters. Keep the active index choice and update timestamp unchanged.

Examples#

Run this internal fixture in a disposable database as superuser. Build and verify a scalar-produced whole-sequence generation without changing the active read policy.
