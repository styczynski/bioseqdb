bioseq_internal.read_minimizer_fixture

SQL test entry point for checking a minimizer generation and its source. Return payload checksums, lookup results, read counts and cache counts. The layout checks currently prevent a successful call: this wrapper accepts layouts 3 and 4, but the reader requires layout 5.

Examples#

Run this internal fixture in a disposable database as superuser. Exercise the legacy reader wrapper with its accepted layout code 3. The current reader requires layout 5, so this call is expected to fail.
