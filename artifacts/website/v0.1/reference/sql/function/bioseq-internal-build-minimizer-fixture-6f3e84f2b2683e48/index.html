bioseq_internal.build_minimizer_fixture

SQL test entry point for building a minimizer generation. Return sourct identity, checksums and write counts after publication. The layout checks currently prevent a successful call: this wrapper accepts layouts 3 and 4, but the builder requires layout 5.

Examples#

Run this internal fixture in a disposable database as superuser. Exercise the legacy fixture wrapper with its accepted layout code 3. The current builder requires layout 5, so this call is expected to fail rather than publish a generation.
