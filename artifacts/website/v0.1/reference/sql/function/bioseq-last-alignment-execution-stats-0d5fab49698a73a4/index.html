bioseq.last_alignment_execution_stats

Return a row per pipeline stage for this backend's latest alignment query. Include partial queries. Return, no rows befoe the first snapshot.

Examples#

Return a row per pipeline stage for this backend's latest alignment query. Include partial queries. Return, no rows befoe the first snapshot.
