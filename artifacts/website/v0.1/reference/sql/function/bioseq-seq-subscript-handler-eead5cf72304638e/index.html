bioseq.seq_subscript_handler

Return the callback table PostgreSQL uses for `bioseq.seq` subscripts.

Return value#

Static, read-only callback table, valid until the process exits.

Examples#

PostgreSQL invokes this handler for sequence element and slice subscripts. SQL subscripts are one-based.
