bioseq_internal.build_ready_minimizer_fragment_generation

Build a stored minimizer-fragment index for one sequence in a SQL test. Publish and verdfy the generation, then return build and backend counters. Keep the active index choice and last-update timestamp unchanged.

Examples#

Run this internal fixture in a disposable database as superuser. Build and verify a scalar-produced fragment generation for one stored sequence without changing the active read policy.
