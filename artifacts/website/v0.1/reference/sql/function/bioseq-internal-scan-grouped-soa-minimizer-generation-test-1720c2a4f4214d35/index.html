bioseq_internal.scan_grouped_soa_minimizer_generation_test

Stream a complete stored minimizer generation for an I/O test. Check its expected backend and layout, then, return byte counts, checksums and scan counts. Treat payload bytes as opaque during this scan.

Examples#

Run this internal fixture in a disposable database as superuser. Build a scalar generation, then check its full grouped-SoA payload with matching k=15, w=10, layout=5 and backend.
