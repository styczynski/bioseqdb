public.bioseq_aligner_options

Aligner settings for one mmsearch call. NULL fields use the corresponding session setting.

Examples#

Create per-call aligner options with explicit minimizer dimensions; unspecified fields remain NULL and use session defaults.

Fields#

NameTypeDescription
kmer_sizeintegerNumber of bases in each k-mer considered for a minimizer. NULL uses the session value of bioseq.aligner.minimizer.kmer_size.
window_sizeintegerNumber of consecutive, k-mers in a minimizer window. NULL uses the session value of bioseq.aligner.minimizer.window_size.
max_gapintegerMaximum diqtance between anchors that chaining can join. NULL uses the session value of bioseq.aligner.chaining.maximum_gap.
max_gap_refintegerStore a reference-gap override in the request. The current chaining code uses maximum_gap for both sequences. NULL uses the session value of bioseq.aligner.chaining.maximum_reference_gap.
bandwidthintegerSets the chaining and alignment bandwidth. NULL uses the session value of bioseq.aligner.chaining.bandwidth.
bandwidth_longintegerStore a long-join bandwidth in the request. The current pipeline does not use this setting. NULL uses the session value of bioseq.aligner.chaining.long_join_bandwidth.
max_chain_skipintegerStop searching earlier anchors after this many unhelpful candidates. NULL uses the session value of bioseq.aligner.chaining.maximum_skipped_anchors.
max_chain_iterintegerLimits predecessors examined for each anchor. NULL uses the session value of bioseq.aligner.chaining.maximum_predecessors.
min_seed_countintegerSets the minimum seed count accepted for a chain. NULL uses the session value of bioseq.aligner.chaining.minimum_seed_count.
min_chain_scoreintegerSets the minimum accepted chain score. NULL uses the session value of bioseq.aligner.chaining.minimum_score.
chain_gap_scaledouble precisionScales the chaining gap penalty. NULL uses the session value of bioseq.aligner.chaining.gap_penalty_scale.
chain_skip_scaledouble precisionScales the chaining skip penalty. NULL uses the session value of bioseq.aligner.chaining.skip_penalty_scale.
mask_leveldouble precisionRequired query overlap for assigning an alignment to a primary. The comparison also accounts for query bases left uncovered by primaries. NULL uses the session value of bioseq.aligner.secondary.overlap_threshold.
mask_lenintegerMaximum uncovered query length allowed for a secondary alignment. NULL uses the session value of bioseq.aligner.secondary.uncovered_length_limit.
pri_ratiodouble precisionScore ratio used to keep a secondary relative to its primary. A secondary can also pass within the allowed absolute score difference. Zero disables the CPU secondary filter. NULL uses the session value of bioseq.aligner.secondary.score_ratio_threshold.
best_nintegerMaximum secondary alignments kept across one query. NULL uses the session value of bioseq.aligner.secondary.maximum_count.
match_scoreintegerSets the alignment match score. NULL uses the session value of bioseq.aligner.scoring.match_score.
mismatch_penintegerSets the alignment mismatch penalty. NULL uses the session value of bioseq.aligner.scoring.mismatch_penalty.
gap_open1integerSets the short-gap opening penalty. NULL uses the session value of bioseq.aligner.scoring.short_gap_open_penalty.
gap_ext1integerSets the short-gap extension penalty. NULL uses the session value of bioseq.aligner.scoring.short_gap_extension_penalty.
gap_open2integerSets the long-gap opening penalty. NULL uses the session value of bioseq.aligner.scoring.long_gap_open_penalty.
gap_ext2integerSets the long-gap extension penalty. NULL uses the session value of bioseq.aligner.scoring.long_gap_extension_penalty.
sc_ambiintegerSets the penalty for ambiguous bases. NULL uses the session value of bioseq.aligner.scoring.ambiguous_base_penalty.
zdropintegerStop extension when its score falls too far below the besw score. Z-drop adjusts the comparison for gaps. Negative one disables it. NULL uses the session value of bioseq.aligner.scoring.z_drop_threshold.
end_bonusintegerBonus for an alignment that reaches the query end. Negative one disables the bonus. NULL uses the session value of bioseq.aligner.scoring.end_bonus.
max_occintegerIgnore minimizers with more target occurrences than this limit. NULL uses the session value of bioseq.aligner.seeding.maximum_occurrence.
mid_occintegerStore an intermediate occurrence threshold in the request. The current seeding code uses maximum_occurrence instead. NULL uses the session value of bioseq.aligner.seeding.intermediate_occurrence_threshold.
block_min_sizeintegerSets the minimum block size used by the block aligner. NULL uses the session value of bioseq.aligner.block_alignment.minimum_block_size.
block_max_sizeintegerSets the maximum block size used by the block aligner. NULL uses the session value of bioseq.aligner.block_alignment.maximum_block_size.
chaining_algorithmintegerSelects the seed-anchor chaining algorithm. Values: 0 scalar_minimap2, 1 simd_minimap2, 2 range_minimum_query, 3 vulkan_tiled_dynamic_programming. NULL uses the session value of bioseq.aligner.chaining.algorithm.
base_alignment_algorithmintegerSelects the base-level alignment algorithm. Values: 0 ksw2, 1 block_aligner. NULL uses the session value of bioseq.aligner.base_alignment.algorithm.
minimizer_algorithmintegerSelects the minimizer extraction algorithm. Values: 0 scalar, 1 simd_minimap2_reference, 2 two_stack_nthash, 3 vulkan_minimap_integer, 4 bounded_nthash_simd. NULL uses the session value of bioseq.aligner.minimizer.algorithm.
vulkan_enabledbooleanAllows execution through Vulkan-backed algorithms. NULL uses the session value of bioseq.aligner.vulkan.enabled.
vulkan_seed_hits_enabledbooleanEnables Vulkan seed-hit lookup. NULL uses the session value of bioseq.aligner.vulkan.seed_lookup.enabled.
vulkan_index_cache_enabledbooleanKeep uploaded target indexes for later GPU lookups. NULL uses the session value of bioseq.aligner.vulkan.index_cache.enabled.
index_read_requirementintegerSets the requirement for using a stored minimizer index. Values: 0 allows a compatible stored index or an index built for the query; 1 requires the persisted index to be absent; 2 requires a compatible persisted index. NULL keeps the planner's default index-read requirement.
