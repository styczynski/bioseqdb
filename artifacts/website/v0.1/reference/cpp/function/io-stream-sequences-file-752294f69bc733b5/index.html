bioseq::io::stream_sequences_file

Reads FASTA or FASTQ on the calling thread and sends packed chunks to

Reads FASTA or FASTQ on the calling thread and sends packed chunks to sink. The, caller selects the packed word type. Completed words can be delivered before a record ends, avoiding a whole-record sequence batch. Header and FASTQ quality parsing still use scratch buffers. Returns the recrd count or the first input or parse error.
