\section{Per-search options}
\label{sec:appendix-search-options}
\label{sec:appendix-options-precedence}

Additionally instead of operating on global settings, user can also provide single object as third parameter to the \texttt{mmsearch} function call.

\info{Parameter encoding}{
  Currently the enum options are encoded by integers - they correspond to the global GUCs, but you can use only numbers. 
  This is just unimplemented feature - the types of the options should be changed to strings and encoded to internal enum int values.
  It was requiring less effort to expose internal representation, so it was left as is, see listing below~\ref{lst:configuration-options}.
}

Encoding of parameters as integer values:
\begin{lstlisting}[style=bioseq-search-sql,
  caption={Passing options by 3rd argument of mmsearch},
  label={lst:configuration-options}]
SELECT (public.aligner_options(
  minimizer_algorithm => 0,
  index_read_requirement => 1)).*;
\end{lstlisting}
