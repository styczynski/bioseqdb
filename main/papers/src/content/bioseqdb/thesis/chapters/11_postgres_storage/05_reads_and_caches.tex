\subsection{BioseqDB all cache layers}
\label{sec:pg-storage-caches}

As presented in previous figures as "chunk cache"~\ref{fig:sequence-scan-lifecycle}~\ref{lst:sequence-scan-lifecycle-steps} and as "column cache"~\ref{fig:execcustomscan-dispatch}, there's 
cache for column decompression.

The cache is disabled by default, but can be enabled by setting \path{bioseq.column_cache.enabled} to \path{true}.
It stores decoded compressed chunks inside one PostgreSQL backend process. Its key contains relation, stripe, chunk
group, and column identifiers (the configured
capacity when enabled defaults to 200~MiB)

The cache can return borrowed pointer to a decompression buffer for a chunk, which allows to prevent additional chunk loads wasting time on decompression multiple times.
