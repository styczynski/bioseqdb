\section{Alignment as a model of biological correspondence}
\label{sec:alignment-model}

Sequence search and sequence alignment are related, but they are not the same
operation. A search procedure asks where useful correspondences might exist.
An alignment describes one such correspondence symbol by symbol. This
distinction is the organizing idea behind modern mappers. Exhaustive dynamic
programming can solve a precisely stated pairwise problem, but it is too
expensive to apply to every possible reference interval. Seed--chain--extend
methods first generate a small set of plausible intervals, then apply dynamic
programming only there. Graph methods change the object against which the query
is compared. They can represent several reference alternatives at once, but
they do not remove the need to define alignment scores and paths.

Let \(X=x_1x_2\ldots x_n\) and \(Y=y_1y_2\ldots y_m\) be strings over an
alphabet \(\Sigma\). A pairwise alignment is a sequence of columns
\[
  A=((a_1,b_1),\ldots,(a_L,b_L)),
  \qquad
  (a_\ell,b_\ell)\in
  (\Sigma\cup\{-\})^2\setminus\{(-,-)\},
\]
such that deleting gaps from \(a_1\ldots a_L\) recovers \(X\), and deleting
gaps from \(b_1\ldots b_L\) recovers \(Y\). A column containing two symbols is
a match or substitution. A symbol aligned to a gap represents an insertion or
deletion relative to the other sequence. An alignment is therefore an explicit
correspondence under a scoring and boundary model, not merely a visual
formatting of two strings. When evolutionary homology is the scientific
question, an alignment can contribute evidence to a homology hypothesis, but
an alignment score alone does not establish common ancestry.

A scoring model turns that hypothesis into an optimization problem. Let
\(s(a,b)\) denote a substitution score and let \(g(\ell)\) be the cost of a
gap run of length \(\ell\). The score of an alignment can be written as
\[
  S(A)=
  \sum_{\text{symbol--symbol columns }\ell}s(a_\ell,b_\ell)
  -\sum_{\text{gap runs }r}g(|r|).
\]
This chapter uses the affine convention
\begin{equation}
  g(\ell)=q+\ell e,\qquad \ell\geq 1,
  \label{eq:affine-gap-convention}
\end{equation}
where \(q\) is a gap-open cost and \(e\) is a per-symbol extension cost.
Some literature and software instead writes \(q+(\ell-1)e\). Neither notation
is intrinsically preferable, but parameter values cannot be transferred
between the conventions without adjustment. BioSeqDB follows the contracts of
the selected alignment kernel, so later chapters state the convention whenever
scores are compared.

The affine form captures an important biological prior. One insertion of ten
bases is normally more plausible than ten independent one-base insertion
events. Charging \(q\) once and \(e\) for each base makes a long run cheaper
than repeatedly opening new gaps. Gotoh showed how to compute this model with
a constant number of states per dynamic-programming cell rather than scanning
all possible gap lengths.\footnote{O. Gotoh, ``An improved algorithm for
matching biological sequences'', \emph{Journal of Molecular Biology} 162
(1982), pp.~705--708,
\url{https://doi.org/10.1016/0022-2836(82)90398-9}.}

\subsection{Global, local and free-end objectives}
\label{subsec:alignment-modes}

The recurrence alone does not determine the alignment problem. Boundary
conditions and traceback endpoints determine which parts of the two strings
must participate. Three objectives are especially important:

\begin{description}
  \item[Global alignment] aligns both strings from end to end. It is suitable
  when the inputs are expected to describe the same complete object. The
  classical Needleman--Wunsch formulation fixes the traceback at opposite
  corners of the dynamic-programming matrix.\footnote{S. B. Needleman and
  C. D. Wunsch, ``A general method applicable to the search for similarities
  in the amino acid sequence of two proteins'', \emph{Journal of Molecular
  Biology} 48 (1970), pp.~443--453,
  \url{https://doi.org/10.1016/0022-2836(70)90057-4}.}

  \item[Local alignment] chooses the best pair of substrings. Scores are
  allowed to restart at zero, and traceback begins at the best cell and ends
  where the score reaches zero. Smith--Waterman gives the standard exact
  recurrence.\footnote{T. F. Smith and M. S. Waterman, ``Identification of
  common molecular subsequences'', \emph{Journal of Molecular Biology} 147
  (1981), pp.~195--197,
  \url{https://doi.org/10.1016/0022-2836(81)90087-5}.}

  \item[Semi-global and overlap alignment] require selected ends but make
  other leading or trailing gaps free. A read-to-reference fit, for example,
  may require the entire read while allowing the selected reference interval
  to have unaligned flanks. Overlap alignment instead looks for a suffix of
  one sequence matching a prefix of the other.
\end{description}

These names are useful shorthand, but software APIs often provide finer
combinations. Ends-free, extension, clipping and local-extension modes differ
in which matrix borders are free and which endpoint is fixed. The current
figure reconstruction specification, DOC0367, records eight such boundary
patterns. The unifying rule is simple: a fixed corner or penalized border
requires the alignment to account for that end, while a free border allows
traceback to start or stop there without paying for the omitted flank.

This observation prevents a common conceptual error in mapper descriptions.
Minimap2 and BioSeqDB do not solve one unconstrained local alignment over an
entire chromosome. Anchors determine candidate regions. Inter-anchor segments
are posed as global fills, while the two outer portions are extension
problems. Minimap2 can terminate a nominally global inter-anchor fill with
Z-drop when the accumulated score deteriorates too quickly.\footnote{H. Li,
``Minimap2: pairwise alignment for nucleotide sequences'',
\emph{Bioinformatics} 34 (2018), pp.~3094--3100, Section~2.2.3,
\url{https://doi.org/10.1093/bioinformatics/bty191}.} BioSeqDB's KSW2 route
normally uses configured band and Z-drop limits. Its edit-distance accounting
route disables both limits for a gap fill. The Block Aligner route uses global
mode for inter-anchor fills and X-drop for outer extension. The final record is
therefore assembled from several related dynamic-programming problems whose
stopping policies must be reported with the chosen backend.

\section{Exact dynamic programming}
\label{sec:exact-dp}

\subsection{Linear-gap recurrence}

For a linear gap cost \(d\), let \(H_{i,j}\) be the best score for prefixes
\(X[1..i]\) and \(Y[1..j]\). A global recurrence is
\begin{equation}
 H_{i,j}=\max
 \begin{cases}
   H_{i-1,j-1}+s(x_i,y_j),\\
   H_{i-1,j}-d,\\
   H_{i,j-1}-d.
 \end{cases}
 \label{eq:nw-recurrence}
\end{equation}
With \(H_{0,0}=0\), \(H_{i,0}=-id\), and \(H_{0,j}=-jd\), this computes a
global score. Adding \(0\) as a fourth candidate and initializing the borders
to zero yields the local Smith--Waterman score. Free-end objectives alter the
initialization and the set of cells from which traceback may begin.

Each cell represents a state \((i,j)\), meaning that \(i\) symbols of \(X\)
and \(j\) symbols of \(Y\) have been consumed. A diagonal transition consumes
one symbol from each sequence. Vertical and horizontal transitions consume
one symbol from only one sequence. A traceback from the chosen terminal cell
therefore spells an edit path and can be run-length encoded as a compact
idiosyncratic gapped alignment report (CIGAR) string. For example,
\(10\mathtt{M}1\mathtt{I}4\mathtt{M}\) denotes ten aligned
symbol pairs, one insertion, then four more aligned pairs. Whether
\(\mathtt{M}\) is later refined to exact-match \(\mathtt{=}\) and mismatch
\(\mathtt{X}\) is an output convention.

\subsection{Affine and two-piece affine gaps}

An affine model needs separate states because the cost of extending a gap is
different from the cost of opening one. Let \(M_{i,j}\) end with a
symbol--symbol column, \(I_{i,j}\) end with a gap in \(X\), and \(D_{i,j}\)
end with a gap in \(Y\). Under the convention in
Equation~\ref{eq:affine-gap-convention},
\begin{equation}
\begin{aligned}
 M_{i,j} &=
   \max\{M_{i-1,j-1},I_{i-1,j-1},D_{i-1,j-1}\}
   +s(x_i,y_j),\\
 I_{i,j} &= \max\{M_{i,j-1}-q-e,\ I_{i,j-1}-e\},\\
 D_{i,j} &= \max\{M_{i-1,j}-q-e,\ D_{i-1,j}-e\},\\
 H_{i,j} &= \max\{M_{i,j},I_{i,j},D_{i,j}\}.
\end{aligned}
\label{eq:gotoh-recurrence}
\end{equation}
Appropriate sentinel values prevent impossible boundary transitions. Local
alignment additionally permits a restart at zero. Traceback stores or
reconstructs which candidate produced each state.

A single affine function is not equally realistic for short and very long
gaps. Minimap2 therefore uses a two-piece affine cost
\begin{equation}
  g_2(\ell)=
  \min(q_1+\ell e_1,\ q_2+\ell e_2).
  \label{eq:two-piece-affine}
\end{equation}
The first component can model short insertions and deletions, while the second
has a larger open cost and smaller extension cost for long events. The DP
adds a second insertion state and a second deletion state. BioSeqDB's Highway
KSW2 port exposes both single- and dual-affine modes through the unified
\texttt{KswAlignerMode} template. Its module comment and types in
\path{main/bioseq/backend/alignment_hwy/ksw2.cppm} document the
Suzuki--Kasahara difference states used by the implementation. The alternative
Block Aligner backend is deliberately single-affine.

\begin{algorithm}[ht]
  \caption{Affine-gap global alignment with score and traceback states}
  \label{alg:affine-dp}
  \begin{algorithmic}[1]
    \Require sequences \(X[1..n]\), \(Y[1..m]\), substitution score \(s\),
      gap-open cost \(q\), extension cost \(e\)
    \State initialize \(M,I,D\) for the selected boundary objective
    \For{\(i=1,\ldots,n\)}
      \For{\(j=1,\ldots,m\)}
        \State \(M_{i,j}\gets
          \max(M_{i-1,j-1},I_{i-1,j-1},D_{i-1,j-1})+s(x_i,y_j)\)
        \State \(I_{i,j}\gets
          \max(M_{i,j-1}-q-e,I_{i,j-1}-e)\)
        \State \(D_{i,j}\gets
          \max(M_{i-1,j}-q-e,D_{i-1,j}-e)\)
        \State store a predecessor code for each winning state
      \EndFor
    \EndFor
    \State choose the terminal cell permitted by the objective
    \State follow predecessor codes to an allowed initial cell
    \State reverse and run-length encode the resulting operations
    \State \Return score, endpoints and CIGAR
  \end{algorithmic}
\end{algorithm}

\subsection{Cost, banding and stopping criteria}

Filling an \(n\times m\) matrix costs \(O(nm)\) time. A score alone can be
computed with \(O(\min(n,m))\) memory because each row depends on only nearby
rows. Direct traceback generally retains \(O(nm)\) predecessor information,
or trades memory for recomputation. Even quadratic time becomes prohibitive
when one input is a read and the other is a large genome.

Several optimizations reduce the evaluated state space without changing the
recurrence inside it. A banded aligner computes only cells satisfying
\(|i-j-\delta|\le b\) for an expected diagonal \(\delta\) and half-width
\(b\). This changes work to roughly \(O(b(n+m))\), but a band that excludes
the true path changes the result. A mapper can choose the band from seed
geometry, widening it when anchors imply an indel. Z-drop and X-drop terminate
an extension when its current score has fallen sufficiently far behind the
best score observed. They are endpoint heuristics for extension, not
substitutes for the affine recurrence.

Single-instruction, multiple-data (SIMD) execution does not change the
optimization objective when it evaluates the same cells with the same
precision, boundary conditions, stopping policy, and tie policy. The
Suzuki--Kasahara difference formulation stores bounded
differences between neighboring scores, which makes narrow integer lanes
practical and is the basis of KSW2.\footnote{H. Suzuki and M. Kasahara,
``Introducing difference recurrence relations for faster semi-global
alignment of long sequences'', \emph{BMC Bioinformatics} 19, 45 (2018),
\url{https://doi.org/10.1186/s12859-018-2014-8}.} BioSeqDB ports that
formulation to Google Highway so one source can dispatch to SSE, AVX, NEON,
SVE, WebAssembly SIMD, and other supported targets. The Block Aligner backend
uses a different geometric optimization. It maintains a square block around
the promising part of the matrix and slides, grows, or shrinks that block
instead of visiting the full rectangle. The adaptive greedy band can return a
suboptimal score, particularly when large gaps lead the block away from the
optimal path.\footnote{D. Liu and M. Steinegger, ``Block Aligner: an adaptive
SIMD-accelerated aligner for sequences and position-specific scoring
matrices'', \emph{Bioinformatics} 39 (2023), btad487,
\url{https://doi.org/10.1093/bioinformatics/btad487}.} BioSeqDB's current
backend uses global mode for inter-anchor fills and native two-confirmation
X-drop for outer extension. The details and measured trade-offs are developed
in the final-alignment chapter.

\section{Seed--chain--extend}
\label{sec:seed-chain-extend}

\subsection{Why candidate generation is necessary}

Unbanded local dynamic programming between a query of length \(m\) and a
reference of length \(N\) requires \(O(Nm)\) cell evaluations. Most reference
positions cannot belong to a useful alignment. A mapper therefore seeks a
cheap signal that is likely to survive a true alignment but is infrequent in
unrelated intervals. Exact or hashed short substrings provide that signal.

The seed--chain--extend pattern separates the problem into three abstractions:

\begin{enumerate}
  \item \emph{Seeding} selects query substrings and finds compatible
  occurrences in the reference.
  \item \emph{Chaining} selects a collinear subset of those matches and turns
  isolated hits into candidate regions.
  \item \emph{Extension} performs base-level dynamic programming between and
  around the anchors, then emits coordinates, a score, optionally a CIGAR, and
  a mapping quality (MAPQ).
\end{enumerate}

This is a heuristic search wrapped around a dynamic-programming recurrence.
Missing all seeds for a true locus causes a false negative before alignment
begins. Repetitive seeds cause excess candidates and extra work. Chaining may
also discard a useful set of anchors. The recurrence is exact for the cells and
boundaries that are actually evaluated. A route-level result can still be
approximate because a static band, an adaptive block, Z-drop, or X-drop may
exclude part of the unconstrained state space. Sensitivity and optimality must
therefore be discussed stage by stage rather than by calling the whole mapper
either exact or approximate.

\subsection{Seeds and minimizer sketches}

An exact \(k\)-mer seed is a length-\(k\) word occurring in both sequences.
Indexing every \(k\)-mer maximizes the available exact evidence, but creates a
large index and many redundant neighboring hits. A minimizer sketch selects a
representative \(k\)-mer from each window of \(w\) consecutive \(k\)-mers,
usually the minimum under a hash order. Consecutive windows overlap, so the
same representative often persists and is emitted once. This retains a
locally dense sampling property while reducing storage and lookup work.
Roberts and colleagues introduced the minimizer idea to reduce storage for
sequence comparison.\footnote{M. Roberts, W. Hayes, B. R. Hunt, S. M. Mount
and J. A. Yorke, ``Reducing storage requirements for biological sequence
comparison'', \emph{Bioinformatics} 20 (2004), pp.~3363--3369,
\url{https://doi.org/10.1093/bioinformatics/bth408}.}

Canonical DNA seeds treat a \(k\)-mer and its reverse complement as one key,
while retaining a strand bit. The reference index maps each key to one or more
positions. Looking up a query minimizer produces seed hits. Very frequent
keys are often suppressed or down-weighted because they carry little location
information and can dominate memory. Later chapters distinguish BioSeqDB's
scalar, two-stack SIMD, SIMD-Minimizers-derived and Vulkan extraction routes.
For the present chapter, the important invariant is that a hit becomes an
anchor with a reference coordinate, query coordinate, orientation and span.

\subsection{Anchors as points in a coordinate plane}

Plot an anchor \(a_i\) at \((x_i,y_i)\), where \(x_i\) is its reference end
position and \(y_i\) its query end position. Hits from an ungapped alignment
lie near one diagonal because \(x_i-y_i\) is nearly constant. Insertions and
deletions change the diagonal by a bounded amount. Random matches are scattered.
Chaining is therefore a sparse path problem in this two-dimensional plane.

In minimap2 notation, an anchor has span \(w_i\). After sorting anchors by
reference and query order, a chaining score can be written
\begin{equation}
 f(i)=\max\left(
     w_i,\ 
     \max_{j<i}\{f(j)+\alpha(j,i)-\beta(j,i)\}
   \right),
 \label{eq:minimap2-chain}
\end{equation}
where \(\alpha\) rewards newly covered matching bases and \(\beta\) penalizes
large gaps and diagonal changes. A representative minimap2 reward is
\[
  \alpha(j,i)=
  \min\bigl(
    \min(y_i-y_j,\ x_i-x_j),\ w_i
  \bigr).
\]
Pairs with reversed order, excessive distance, or excessive diagonal
deviation are invalid. The gap penalty combines a linear component with a
small logarithmic component. Backtracking predecessor pointers from high
scoring endpoints yields ordered anchor chains.

The recurrence is exact only relative to its candidate predecessor set and
its scoring function. Testing every \(j<i\) is \(O(A^2)\) for \(A\) anchors.
Minimap2 scans a bounded recent window and stops after a configured number of
unproductive predecessors, making the usual cost much smaller while retaining
the same local scoring rule.\footnote{H. Li, ``Minimap2: pairwise alignment
for nucleotide sequences'', \emph{Bioinformatics} 34 (2018),
pp.~3094--3100, \url{https://doi.org/10.1093/bioinformatics/bty191}.}
Range-minimum-query methods accelerate a related formulation for long gaps.
SIMD and tiled GPU implementations instead evaluate several predecessor
scores together. These are not interchangeable labels. One changes the data
structure and search formulation, another changes the execution of the
predecessor loop, and a bounded approximate policy may change which endpoint
is selected.

BioSeqDB preserves this distinction in its current API. The
\texttt{ChainingAlgorithmType} enum in
\path{main/bioseq/backend/pipeline/minimap_port.cppm} exposes scalar minimap2,
SIMD minimap2, RMQ and Vulkan tiled-DP routes. The shared
\texttt{compute\_chaining\_score} function in
\path{main/bioseq/backend/sequences/chaining/chaining_utils.cppm} rejects
invalid geometry, rewards new coverage, then applies linear and logarithmic
penalties. The current \texttt{Anchor} is a flat 24-byte object with 64-bit
stored coordinates. The scoring helper narrows predecessor reference and query
distances to signed 32-bit values, consistent with its 32-bit distance
parameters, before geometry checks and penalties. This is an important
difference from early April design notes, which discussed older packed layouts
and must not be read as the present implementation.

\begin{algorithm}[ht]
  \caption{Conceptual bounded predecessor chaining}
  \label{alg:anchor-chaining}
  \begin{algorithmic}[1]
    \Require anchors \(a_1,\ldots,a_A\) in canonical coordinate order
    \For{\(i=1,\ldots,A\)}
      \State \(f[i]\gets \operatorname{span}(a_i)\)
      \State \(p[i]\gets \bot\)
      \For{candidate \(j<i\) in the active distance and iteration window}
        \If{\(a_j\) and \(a_i\) have valid order, strand, gap and bandwidth}
          \State \(v\gets f[j]+\operatorname{reward}(a_j,a_i)
            -\operatorname{gapPenalty}(a_j,a_i)\)
          \If{\(v>f[i]\)}
            \State \(f[i]\gets v\), \(p[i]\gets j\)
          \EndIf
        \EndIf
        \State optionally stop after the configured skip heuristic fires
      \EndFor
    \EndFor
    \State backtrack from high-scoring endpoints through \(p\)
    \State filter chains by score, seed count and overlap
  \end{algorithmic}
\end{algorithm}

\subsection{From chains to base-level alignment}

A chain supplies orientation and approximate query and reference intervals.
It also divides the work into left extension, mandatory gaps between anchors,
and right extension. The anchors themselves account for exact matching
segments. Dynamic programming fills the intervening pieces and decides
whether an apparent displacement is better represented by substitutions or
gaps. Traceback concatenates the resulting operations with the anchored
matches.

Minimap2's base-level route calls KSW2 with a band, two-piece affine gaps and
Z-drop. BioSeqDB's ordinary KSW2 gap fills likewise use configured band and
Z-drop values. When exact edit-distance accounting is requested, its
inter-anchor calls disable both limits. The Block Aligner alternative requests
global mode for those fills and uses X-drop for the outer extensions. Its
adaptive block geometry still means that global mode is not a proof of an
unbanded optimum. Minimap2's source-level sequence is visible in the local
comparison copy:
\texttt{mm\_sketch} in \path{minimap2-master-clean/sketch.c},
\texttt{mm\_collect\_matches} in
\path{minimap2-master-clean/seed.c}, \texttt{mg\_lchain\_dp} in
\path{minimap2-master-clean/lchain.c}, then
\texttt{mm\_align\_skeleton} and \texttt{ksw\_extd2\_sse} in
\path{minimap2-master-clean/align.c}. BioSeqDB retains the same conceptual
sequence but exposes several implementations at each stage. Current
\path{main/bioseq/backend/pipeline/minimap_port.cppm} names nine high-level
steps: target minimizer index construction, seed collection, chaining, region
generation, primary/secondary classification, filtering, dual-affine
alignment, mapping-quality calculation and result construction.

coordinates,
uses C++ modules and explicit algorithm selectors, employs Highway SIMD,

with database-resident indexes. Later chapters evaluate whether particular
routes preserve bit-identical sketches or exact chain endpoints. This chapter
only establishes the common algorithmic vocabulary needed to interpret those
measurements.

\section{Graph-based sequence representations}
\label{sec:graph-approaches}

\subsection{Why replace one reference string by a graph?}

A linear reference chooses one sequence for each locus. Real populations
contain alternative alleles, insertions, deletions and rearrangements. Reads
carrying a non-reference allele may receive a worse score simply because the
chosen linear string omits that allele. A sequence graph can retain shared
context once and branch where alternatives differ. An alignment is then a
mapping of the query to a path through the graph.

Two graph families are often conflated:

\begin{description}
  \item[Variation or sequence graphs] explicitly represent reference segments
  as nodes or node labels and alternative adjacencies as edges. A path spells
  a haplotype or another permitted sequence. The vg toolkit demonstrated a
  practical variation-graph framework for genome inference and mapping.
  \footnote{E. Garrison et al., ``Variation graph toolkit improves read mapping
  by representing genetic variation in the reference'', \emph{Nature
  Biotechnology} 36 (2018), pp.~875--879,
  \url{https://doi.org/10.1038/nbt.4227}.}

  \item[de Bruijn graphs] represent local substring adjacency. In an order-\(k\)
  construction, a common convention uses \((k-1)\)-mers as nodes and observed
  \(k\)-mers as directed edges from their prefix to their suffix. A walk spells
  a sequence by appending one symbol per edge. These graphs are foundational
  in genome assembly because reads contribute local \(k\)-mer evidence without
  requiring a known global placement.\footnote{P. A. Pevzner, H. Tang and
  M. S. Waterman, ``An Eulerian path approach to DNA fragment assembly'',
  \emph{Proceedings of the National Academy of Sciences} 98 (2001),
  pp.~9748--9753, \url{https://doi.org/10.1073/pnas.171285098}.}
\end{description}

The de Bruijn construction changes assembly from choosing an ordering of
whole reads to finding a walk that uses local adjacency evidence. Under ideal
conditions, reconstruction can be stated as an Eulerian path problem over
edges. This should not be confused with an overlap graph, in which reads are
vertices and compatible suffix--prefix overlaps are edges. Nor should it be
confused with pairwise alignment. The graph supplies a reference language.
An aligner must still score how the query follows a graph path and where it
uses substitutions, insertions or deletions.

\subsection{Dynamic programming on a graph}

For a linear target, the alignment state \((i,j)\) identifies a query prefix
and one target position. For a node-labeled directed acyclic graph, a
corresponding state can be written \((i,v,o)\), where \(i\) is the query
position, \(v\) a graph node, and \(o\) an offset within its label. A
symbol--symbol transition advances both the query and graph path. A query
insertion advances only the query. A deletion advances only the graph path.
At a branch, the recurrence considers incoming or outgoing graph edges.

If the graph is acyclic, nodes can be processed in topological order.\footnote{
C. Lee, C. Grasso and M. F. Sharlow, ``Multiple sequence alignment using
partial order graphs'', \emph{Bioinformatics} 18 (2002), pp.~452--464,
\url{https://doi.org/10.1093/bioinformatics/18.3.452}.} Cycles
from repeats or de Bruijn structure complicate this order and require
additional restrictions, indexing, graph transformations or search
algorithms. The state space scales with the represented graph, not with the
length of one chosen path. Repeated \(k\)-mers collapse into the same de
Bruijn nodes and can make origin ambiguous. Increasing \(k\) resolves some
repeats but needs longer exact context and makes the graph more sensitive to
coverage gaps and errors. Decreasing \(k\) improves local connectivity while
collapsing more repeats. The value of a graph is therefore coupled to its
construction and indexing policy.

At genome scale, candidate reduction remains practically essential. Graph
mappers commonly find seeds in graph paths or a graph-derived index, cluster
or chain the corresponding positions, then align against a local subgraph.
The search space is richer
than in a linear reference because one seed may correspond to many paths.
Graph representation can reduce reference-allele bias, but it introduces path
selection, index size, update and output-coordinate questions. A database
system must additionally decide how graph nodes, named paths and annotations
participate in relational joins and versioning.

\subsection{Relation to BioSeqDB}

BioSeqDB's current mapper is a linear-reference seed--chain--extend system.
Its anchor contract stores one reference coordinate and a strand, and current
code explicitly removes a reference identifier from the 24-byte anchor because
the active fragment index is single-target. The pipeline may process many
stored sequences and many target fragments, but each mapping problem still
chains against a linear coordinate system. This is an implementation fact, not
a claim that graph references are unimportant.

A graph-native BioSeqDB mapper would require more than substituting a graph
table for a text column. Seeds would need graph positions or path coordinates.
Chaining would need a reachability-aware order rather than a single increasing
reference coordinate. Extension would need graph DP or extraction of a local
linearized subgraph. Output would need stable node, path and version
identifiers that can be joined with relational metadata. Persistent indexes
would need update semantics compatible with graph changes. These are valuable
research directions, but they are not silently supplied by the present
minimap2-derived pipeline.

\section{Choosing an approach}
\label{sec:choosing-alignment-approach}

No single method dominates for every task. Exhaustive dynamic programming is
the clearest exact model for two moderate strings. Seed--chain--extend is a
practical strategy when searching long references or large collections,
provided its sensitivity and repetitive-seed behavior are understood. Graph
mapping is appropriate when representing alternatives is itself part of the
problem, at the cost of a more complex reference, index and coordinate model.
These choices are not mutually exclusive. A target representation answers what
sequences or paths exist, while a search strategy answers how candidate
regions are found and refined. A graph mapper can therefore use
seed--chain--extend, and a linear target can be searched by methods other than
that strategy.
